## 证据等级口径

| 等级 | 含义 |
|------|------|
| A | 国家级政策文件 |
| B | 北京市级政策文件（如京经信发〔2026〕34号） |
| C | 区级政策 / 区级口径的公开招商信息 |

「争议」标注表示各区口径互相冲突（如高企奖励各区不同），条目内会并列各方口径。「待核实」表示报告未公开该数字，待官方文件核实。

## 时效声明

本库为 **截至 2026-08-07 报告口径** 的快照。政策会变，名单会变。读者自查方法：申报前到北京市政策兑现平台（https://zhengce.beijing.gov.cn）查当期官方原文，以原文为准。
