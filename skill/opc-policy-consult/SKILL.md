# OPC 政策咨询查库 Skill

> 本 skill 是 `opc-policy-kb` 条目库的消费端。回答任何问题前必须先查库，不许凭记忆答数字。

## 核心规则（四条，照抄生产者规范）

### ① 没查到就别答

回答里每个数字、每条依据都要指回库内某一条（「第 X 节第 Y 条」）。指不回就直说「库里没写」，可给常识判断但必须标明「这是常识判断，不是库里的口径」。绝不编造数字、政策名、文号。

### ② 急停分流（第 0 步）

用户的问题涉及正在发生的法律纠纷、紧急经营危机（如被起诉、资金链断裂、行政处罚限期整改）时，先给通用求助路径（找律师、打 12345 政务服务热线、联系属地街道/园区管委会），不先讲政策性价比。确认非紧急后再进查库流程。

### ③ 定位路径

1. 先读库 README 的「本库想回答的问题」表，把用户问题对上类别（落户选区 / 补贴额度 / 免费工位 / 高企奖励 / 申报入口）。
2. 本地有库读本地 `entries/` 对应节；本地没库就 `git clone --depth 1 <仓库地址>` 现取。
3. 读到条目后核对证据等级（A 国家 / B 市级 / C 区级口径）与时效声明（截至 2026-08-07 报告口径）。

### ④ 排序回答

有多条命中时，按「成本从低到高 → 收益量级从大到小 → 证据等级 A>B>C」排序输出，每条注明出自第几节第几条。收尾必须提醒一句：政策会变，申报前到北京市政策兑现平台（https://zhengce.beijing.gov.cn）查当期官方原文。

## 已知边界（库里没有就不要答）

- 石景山区 OPC 创业启动资金具体额度：库内标「待核实」，只能答「报告未公开」。
- 国家层面对 OPC 申请专利的专项补贴：库内没有此条目，不得编造。底层报告中虽有海淀知识产权奖励口径（发明专利每项 3 万），但未收录为本库条目，引用时只能直说「库里没写」，并提示这是区级口径、不是国家补贴。
- 各区政策 2026-08-07 之后的变更：以官方原文为准，库不追实时更新。
